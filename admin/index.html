پروژه‌ها

چیدمان کارت‌ها

کارت‌ها رو بکش تا جاشون عوض شه. گوشه‌ی پایین کارت رو بکش تا اندازه‌اش عوض شه. با انتخاب یه کارت، چرخشش رو از پایین تنظیم کن. (روی گوشی کارت‌ها خودکار زیر هم چیده میشن.)

تب‌های پوشه

ترتیب تب‌ها همون ترتیب روی پوشه‌ست. اسم تب رو عوض کنی، پروژه‌هاش هم خودکار منتقل میشن. (حروف کوچیک انگلیسی بهترن، چون با فونت سایت کشیده میشن.)

    متن درباره (about)

    هر کادر یه پاراگرافه.

    عمومی

    کلمه‌های صفحه اول (که روشن و خاموش میشن)

    تاریخچه نسخه‌ها

    هر بار که «انتشار» می‌زنی یه نسخه ثبت میشه. با «برگرد به این نسخه» محتوای اون نسخه توی پنل بار میشه؛ بعد اگه خوب بود انتشارش بده.

      اتصال به گیت‌هاب

      1. این صفحه رو باز کن: ساخت توکن گیت‌هاب ↗
      2. یه اسم بده (مثلاً rocket-admin) و تاریخ انقضا انتخاب کن.
      3. Repository access ← Only select repositories ← ریپو rocket-effect.
      4. Permissions ← Repository permissions ← Contents رو بذار روی Read and write.
      5. Generate token رو بزن، توکن رو کپی کن و اینجا بذار.

      توکن فقط توی همین مرورگر می‌مونه و جز به خود گیت‌هاب جایی فرستاده نمیشه. بدون توکن هم می‌تونی ویرایش و پیش‌نمایش کنی، فقط انتشار نیاز به اتصال داره.
